# Community leaderboard (preview)
Run python3 server/leaderboard.py behind an HTTPS reverse proxy with request rate limits and a persistent CLAY_DB path. Configure clay/leaderboard_url in project.godot to the HTTPS origin. The game sends an anonymous random identifier and local best only when the player taps Submit best. No endpoint is configured by default. Scores are client-reported and explicitly unverified; do not use for prizes, competitive events, or trusted ranking until server replay validation and authentication are implemented. Back up the SQLite file. Restrict public access to the proxy, not the local port.
